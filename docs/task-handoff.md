# 任务交接：模型蔬果流水线分拣

记录日期：2026-10-19。用户暂时处理其他事情，要求记住任务；开发已暂停，等待用户主动恢复。

## 最终目标与责任

最终完成输送带上的轻质模型蔬果识别、定位、机械臂/灵巧手抓取、分类投放与连续循环，并经过现场验收。
参考上传的静止抓取程序复用已有经验，最终交付不是静止抓取演示或云端模拟通过。
助手负责软件实现、识别/训练流程、设备适配、自动测试、文档及按现场结果修正；用户提供设备资料、实际图像/标定，并在现场配合操作和验收。

## 已确认条件

- 平台：Ubuntu 22.04 / ROS 2 Humble / Python 与 C++。
- 机械臂：AUBO K5；灵巧手：睿研智控 RY-H1 标准版，16 自由度，使用 CAN。
- 相机：Intel RealSense L515；上传代码采用眼在手上方案，实际安装与有效标定仍需核对。
- 静止抓取现行入口由用户确认：`demo3_autograsp.py` 的任务 1。
- 模型蔬果首批：苹果、香蕉、梨子、西红柿，标签 `apple`、`banana`、`pear`、`tomato`；物品重量很轻。
- 输送带能手动调速、暂停，程序控制接口尚未确认。
- 实施路线：停带抓取；先进行手动停带条件下的半自动现场验收，再接入输送带控制器实现自动循环。持续运动中抓取不是当前第一版范围。
