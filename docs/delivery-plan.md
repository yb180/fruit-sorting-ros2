# 模型蔬果流水线分拣：完成步骤与现场配合

## 最终交付目标

在 AUBO K5 + RY-H1 CAN 灵巧手 + L515 上，将输送带送入的轻质模型蔬果识别、定位、抓取，放入对应类别的料框，连续处理下一件并记录结果。
首批类别已确认为苹果、香蕉、梨子、西红柿，软件标签使用 `apple`、`banana`、`pear`、`tomato`。其他类别需要加入数据、配置与验收后再启用。

最终验收必须使用现场真实图像、标定和设备；云端模拟、单元测试或已上传的静止抓取脚本不能替代现场验收。
用户说明物品是轻质模型，因此第一版以已有抓取动作的适配、定位和流程稳定性为重点，不凭空设置新的抓取力、关节角或负载参数。

## 已确认条件与实施路线

- 现场已有 ROS 2 Humble 静止抓取，当前入口为 `demo3_autograsp.py` 任务 1。
- 灵巧手使用 CAN；上传 Linux 分支采用 SocketCAN，现场适配器、协议版本与当前总线配置待核对。
- 输送带已有调速和暂停能力，目前由人工操作，程序控制接口未确定。
- 相机源码按眼在手上设计；实际安装、工具 TCP 和当前标定结果仍需核对。
- 现有 `last1.pt` 记录的是 `dog`/`bread` 两类检测模型，需要使用实际模型蔬果数据训练或更换经过验证的权重。

采用 **停带抓取** 路线：先完成手动暂停条件下的现场半自动验收，再接入有反馈的输送带启停控制，实现自动循环。
半自动阶段仍需要人暂停和放行输送带，不能称为已完成无人值守流水线。
如果控制器没有外部接口，需先确定厂商支持的控制方式或由现场工程人员选择合适控制器；不能从软件猜测继电器接线或通信协议。
